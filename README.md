# 유하네 식단

가족 저녁 식단·달력·성장표·가계부 웹앱입니다. `index.html` 하나로 동작하며, 사진은 파일 안에 포함되어 있습니다.

## 메모

- 이 저장소는 GitHub Pages로 공개 배포됩니다. 주소를 아는 사람은 누구나 열 수 있습니다.
- 식단 데이터를 새로 받으면 `index.html` 안의 `MEAL_PLAN_DATA` 객체만 바꾸고 다시 올리면 됩니다.
- 가족 기록(일정·유치원 챙길 것·학원·이번 주 식단·장보기 체크·키/몸무게)은 Firebase Realtime Database
  (`rooms/yh8f4k9m2p7x`)에 저장되어 남편 폰과 실시간으로 함께 바뀝니다. 화면은 기기에 먼저 저장(localStorage)되고,
  연결이 끊겨도 기기 기록은 그대로 남았다가 다시 연결되면 올라갑니다.
- 가계부(수입·고정지출·생활비 예산·지출 기록)는 같은 방의 `budget` 노드
  (`{income, groups, living, expenses}`)에 저장됩니다. 고정지출 항목의 이름·금액을 고치면 그룹 소계와 전체 합계,
  고정지출을 뺀 가용 예산이 바로 다시 계산되고, 이번 달 지출 기록은 남은 예산에 반영됩니다. 다른 노드(`duty`·`memos`·`growth`·
  `academy`·`kids`·`plan`·`shop`)는 건드리지 않습니다.
- 지석 님 근무표는 같은 방의 `duty` 노드(`{"2026-12-07": "주", …}`)에 따로 저장됩니다. 코드는 주=주간,
  야=야간, 비=비번, 휴=휴무, 출=출동. 앱을 새로 고치지 않아도 다른 기기에 바로 붙고, 일정(`memos`)과는
  다른 칸이라 메모·성장표·식단을 건드리지 않습니다. 내장 근무표(`d-duty-*`)는 클라우드에 그 날 값이 없을 때만 보입니다.
- 근무표만 바꿀 때는 빌드·배포 없이 `python3 meal-planner/set_duty.py 2026-12-07 주주야휴출` 로 몇 초 만에 넣습니다
  (`--show`, `--clear 시작 끝`, `--dry-run` 지원). `meal-planner/` 는 배포 저장소 밖의 원본 작업 폴더입니다.
- 데이터베이스 보안 규칙은 그 방(room) 경로만 읽기/쓰기 허용으로 열려 있습니다. 주소를 아는 사람은 누구나
  열람·수정할 수 있으니, 가족 외에는 공유하지 마세요.
